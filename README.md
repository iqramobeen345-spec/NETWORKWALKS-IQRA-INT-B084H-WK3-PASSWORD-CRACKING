## 📌 Project Modules

### W3-PM1: Password Cracking with John the Ripper (JTR)

**Objective:** Recover the password of a protected PDF file using John the Ripper and Johnny GUI on Windows.

**Tools Used:**
- John the Ripper (JTR)
- Johnny GUI
- PDF Hash Extractor
- Notepad

**Tasks Performed:**
- Downloaded and configured John the Ripper.
- Installed and configured Johnny GUI.
- Extracted the password hash from a protected PDF.
- Saved the extracted hash in a text file.
- Loaded the hash into Johnny.
- Started a password recovery attack.
- Tested the recovered password by opening the protected PDF.

### W3-PM2: Password Cracking with Networkwalks Tools

**Objective:** Recover the password of a protected PDF using Networkwalks online tools.

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser

**Tasks Performed:**
- Uploaded the protected PDF to the Hash Calculator.
- Extracted the PDF hash.
- Copied the complete hash value.
- Submitted the hash to the Password Cracker.
- Started the dictionary-based password recovery process.
- Retrieved the matching password.
- Verified the result by opening the protected PDF.
